# 🎯 远征 + 5-2出击 组合任务 - 使用指南

## 📋 功能说明

将**远征**和**5-2出击**组合在一起，两个任务并发执行：

- ✅ 远征和5-2同时运行，互不阻塞
- ✅ 远征完成时自动暂停5-2
- ✅ 收取奖励和派出远征期间5-2保持暂停
- ✅ 派出完成后立即恢复5-2出击
- ✅ 使用线程事件机制精确协调

## 🚀 快速开始

### 1. Pipeline 配置

```json
{
  "StartCombinedTasks": {
    "action": "Custom",
    "custom_action": "AutoCombinedTasks",
    "custom_action_param": "{\"mode\": \"start\", \"expedition_config\": {\"fleets\": [{\"id\": 2, \"duration\": 720}, {\"id\": 5, \"duration\": 1200}], \"check_interval\": 10}, \"combat_config\": {\"map\": \"5-2\", \"interval\": 5}}"
  }
}
```

### 2. 停止任务

```json
{
  "StopCombinedTasks": {
    "action": "Custom",
    "custom_action": "AutoCombinedTasks",
    "custom_action_param": "{\"mode\": \"stop\"}"
  }
}
```

## ⚙️ 参数配置

### expedition_config（远征配置）

```json
{
  "fleets": [
    {"id": 2, "duration": 720},   // 2队，12分钟
    {"id": 5, "duration": 1200},  // 5队，20分钟
    {"id": 6, "duration": 900}    // 6队，15分钟
  ],
  "check_interval": 10  // 检测间隔（秒）
}
```

### combat_config（出击配置）

```json
{
  "map": "5-2",      // 地图名称
  "interval": 5      // 出击间隔（秒）
}
```

### 协调机制

```
远征线程                        5-2线程
   │                              │
   ├─检测到完成                   │
   ├─clear()事件 ──────────────→ │
   │                            ├─wait()阻塞
   ├─收取奖励                    │（暂停中）
   ├─派出远征                    │（暂停中）
   ├─set()事件 ────────────────→ │
   │                            ├─wait()通过
   │                            ├─继续出击
   │                              │
```

## 💡 关键特性

### 1. 暂停机制

**什么时候暂停5-2？**

- ✅ 远征完成，开始收取奖励
- ✅ 收取奖励期间
- ✅ 派出新远征期间

**什么时候恢复5-2？**

- ✅ 新远征派出完成
- ✅ 立即恢复，无延迟

### 2. 线程安全

- ✅ 使用 `threading.Event` 控制
- ✅ 不会出现资源冲突
- ✅ 精确的时序控制

### 3. 自动协调

- ✅ 无需手动干预
- ✅ 自动检测和暂停
- ✅ 自动恢复执行

## 📈 效率分析

### 传统方式（顺序执行）

```
远征12分钟 → 5-2出击10次（5分钟）→ 再远征...
总时间：12 + 5 = 17分钟
```

### 组合方式（并发执行）

```
远征12分钟
    ↓
5-2持续出击（12分钟期间）
    ↓
总时间：12分钟（5-2同时进行）
效率提升：约 40%！
```

## ⚠️ 注意事项

1. **远征区域配置**
   - 确保每个舰队有独立的检测区域
   - 区域不应重叠

2. **时长准确性**
   - 远征时长应与实际一致
   - 考虑网络延迟

3. **暂停时长**
   - 收取+派出通常需要3-5秒
   - 5-2会在此期间完全暂停

4. **停止方式**
   - 使用 `stop` 命令优雅停止
   - 或依赖守护线程自动停止
