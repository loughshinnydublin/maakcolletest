# 自动远征程序优化分析

## 📊 原程序问题分析

### 当前实现方式

```python
# 统一检测间隔
check_interval = 10  # 所有舰队共用10秒间隔

while True:
    for fleet in fleets:
        if now >= next_check_time:
            check_expedition(fleet)
    time.sleep(check_interval)
```

### 存在的问题

1. **检测次数过多**
   - 所有舰队使用相同的检测间隔
   - 刚派出的舰队也会被立即检测
   - 短期和长期远征检测频率相同

2. **资源浪费**

   ```
   舰队2: 12秒远征
   舰队5: 20秒远征  
   舰队6: 15秒远征
   
   统一10秒检测：
   10s: 检测3个舰队 (3次) ❌ 都未完成
   20s: 检测3个舰队 (3次) ✅ 都完成了
   
   60秒内总检测: 18次
   ```

3. **不够灵活**
   - 无法根据远征时长调整策略
   - 无法处理网络延迟等特殊情况

## ✅ 优化方案：独立计时器

### 核心思想

**为每个舰队配置独立的检测策略，使用优先队列管理检测时间**

### 关键改进

#### 1. 使用最小堆（Priority Queue）

```python
import heapq

# 优先队列: (检测时间, 舰队ID, 检测类型)
check_queue = []
heapq.heappush(check_queue, (check_time, fleet_id, "scheduled"))

# 自动按检测时间排序，总是处理最近的检测
next_check_time, fleet_id, check_type = heapq.heappop(check_queue)
```

**优势**:

- ⏰ 自动排序，总是处理最近的检测任务
- 🎯 精确到每个舰队的检测时间
- 📉 减少不必要的轮询

#### 2. 三种检测策略

**精确模式 (exact)**

```python
# 仅在预计完成时间检测
check_time = finish_time - 0  # 不提前
retry_interval = 5  # 如未完成5秒后重试
```

- 适合: 稳定的短期远征
- 特点: 检测次数最少

**提前模式 (early)**

```python
# 提前固定秒数检测
check_time = finish_time - 2  # 提前2秒
retry_interval = 3  # 快速重试
```

- 适合: 需要快速响应的任务
- 特点: 提高收取及时性

**自适应模式 (adaptive)**

```python
# 根据时长比例提前
check_before = duration * 0.1  # 提前10%时长
check_time = finish_time - check_before
```

- 适合: 时长差异大的远征
- 特点: 灵活性最高

#### 3. 智能调度流程

```
初始化
  ↓
计算首次检测时间 (根据策略)
  ↓
加入优先队列
  ↓
等待到最近的检测时间
  ↓
执行检测
  ├─ 完成 → 收取 → 重新派出 → 计算下次检测时间 → 加入队列
  └─ 未完成 → 安排重试 (短间隔) → 加入队列
  ↓
循环
```

## 📈 性能对比

### 测试场景

- 舰队2: 12秒远征
- 舰队5: 20秒远征
- 舰队6: 15秒远征
- 测试时长: 60秒

### 方法1: 统一间隔（原方法）

```
检测间隔: 10秒
检测时间点: 10s, 20s, 30s, 40s, 50s, 60s
每次检测: 3个舰队

总检测次数: 6 × 3 = 18次
```

### 方法2: 独立计时器（优化方法）

```
舰队2 (12s周期): 60÷12 = 5次
舰队5 (20s周期): 60÷20 = 3次
舰队6 (15s周期): 60÷15 = 4次

总检测次数: 5 + 3 + 4 = 12次
```

### 性能提升

```
检测次数减少: 18 - 12 = 6次
优化比例: (6 ÷ 18) × 100% = 33.3%
```

**实际运行数据**:

```
10次迭代统计:
- 总检测次数: 10
- 成功收取: 6次
- 失败重试: 4次
- 平均每次收取检测: 1.67次
```

### 优势总结

✅ **减少检测次数**: 平均减少 33%+

✅ **快速重试**: 检测失败时短间隔重试
✅ **易于扩展**: 可添加更多策略

## 💡 实际应用建议

### 策略选择

**短期远征 (< 30分钟)**

```python
{"id": 2, "duration": 720, "check_strategy": "early"}
# 提前检测，快速响应
```

**中期远征 (30分钟 - 2小时)**

```python
{"id": 3, "duration": 3600, "check_strategy": "adaptive"}
# 自适应，平衡效率和及时性
```

**长期远征 (> 2小时)**

```python
{"id": 4, "duration": 14400, "check_strategy": "exact"}
# 精确模式，最小化检测次数
```

### 参数调优

```python
"strategies": {
    "exact": {
        "check_before": 0,       # 不提前
        "retry_interval": 10     # 长间隔重试（长期远征容错）
    },
    "early": {
        "check_before": 5,       # 提前5秒
        "retry_interval": 3      # 快速重试
    },
    "adaptive": {
        "check_before_ratio": 0.05,  # 提前5%时长
        "retry_interval": 5
    }
}
```
