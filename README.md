## 项目说明

该项目是为《舰队collection》设计的自动化工具，是一个兴趣使然的练手项目，由于作者水平有限，该程序：
* 会抢鼠标
* 仅支持poi并且分辨率、布局不能自动适配
* 支持功能简单
* 逻辑有待优化
* 结构有待调整
* 更新速度慢

## 功能

5-2c空丧流练级

```
使用方法:第一梯队配置单舰喷二或3船喷二带老板，回到主页然后开始5-2c任务

注意事项：
确保修理渠有空位，否则旗舰大破后无法修理
执行期间无法发远征
执行期间鼠标会被占用
```

## 计划开发
```
2-4偷紫菜
自动收发远征
1-1刷闪
1-4，2-2，2-3捞船
```
